# Rock Paper Scissors Game

- A simple and fun **Rock Paper Scissors** game.
- Play against the computer, track your score, and enjoy a responsive, modern interface.

## Features

- Interactive gameplay – Choose Rock, Paper, or Scissors.
- Computer opponent – Random move generation.
- Score tracking – Wins, losses, and ties saved in browser `localStorage`.
- Reset option – Clear your score anytime.
- Responsive design – Works on desktop, tablet, and mobile.

## Tech Used

- HTML
- CSS
- JavaScript
