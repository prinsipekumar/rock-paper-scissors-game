# Rock Paper Scissors Game

A fun and interactive **Rock Paper Scissors** game built with **HTML, CSS, and JavaScript**.  
Play against the computer, track your wins/losses/ties, and enjoy a colorful UI with persistent score storage.

---

## Features

- Classic **Rock, Paper, Scissors** gameplay
- Play against a computer opponent (randomized moves)
- **Score tracking** (wins, losses, ties) saved in `localStorage`
- Reset button to clear scores and start fresh
- Responsive design for desktop and mobile
- Fun emojis and vibrant UI styling

---

## Technologies Used

- **HTML5** for structure
- **CSS3** for styling and responsiveness
- **JavaScript (ES6)** for game logic and interactivity
- **localStorage** for persistent score tracking

---

## Getting Started

### 1. Clone the repo

```bash
git clone https://github.com/your-username/rock-paper-scissors.git
cd rock-paper-scissors
```

### 2. Open in browser

Simply open index.html in your browser.
No build step or server required - everything runs client-side.

## How to Play

- Click Rock ✊, Paper ✋, or Scissors ✌️.
- The computer will randomly pick its move.
- The result (win/lose/tie) will be displayed.
- Your score updates automatically and is saved locally.
- Use Reset Score ⟳ to clear your stats.
